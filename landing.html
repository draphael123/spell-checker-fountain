Process

How It Works

Simple, effective, and non-intrusive

1

Type Naturally

Continue typing as you normally would. Fountain runs silently in the background monitoring text fields.

2

Get Notified

When you misspell a word, a subtle popup appears showing the incorrect spelling crossed out and the correct version.

3

Retype Correctly

Delete the misspelled word and type it correctly yourself. This active correction builds lasting memory.

4

Track & Improve

Visit the dashboard to see your progress. Identify trouble words and watch your accuracy improve over time.

Chrome Web Store

The easiest way to install. One click and you're ready to go.

  • Visit the Chrome Web Store listing

Developer Mode

Load the extension directly from source for development or testing.

  • Download or clone the repository
  • Open Chrome and navigate to: chrome://extensions
  • Enable "Developer mode" (top right toggle)
  • Click "Load unpacked" button
  • Select the extension folder
